- topics（6 个）：`developer-portfolio, github-actions, github-profile, profile-readme, readme, snake`

### 注意点
- **topics 只允许小写 ASCII 字母/数字/连字符，中文会被接口拒绝**，
  因此描述用中文、topics 必须保持英文，这是平台约束。
- `PUT /repos/{o}/{r}/topics` 是**整体替换**语义，必须一次传全量 names，
  不能当增量接口用（否则会清空已有 topics）。
- About 字段不随 git 提交，改完即生效，无需 push。
- 该仓库无 LICENSE；License 不算 About，但属门面项，本轮未处理。

  均有完整 description + topics），go-scaffold 与 CrawlerHub 两库
  description 与 topics 均为**空**，是后续可补项。
